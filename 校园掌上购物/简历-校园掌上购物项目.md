## 一、项目描述（可直接用）

校园掌上购物系统是一款面向高校师生的综合性校园电商平台，采用前后端分离架构，包含 **移动端（uni-app）+ 管理后台（Vue 3）+ 服务端（Spring Boot）** 三部分。系统覆盖商品/店铺管理、购物车与订单、论坛互动、在线留言、收藏、出入库、实时通讯、AI 智能问答等业务，支持管理员、商家、用户、游客四类角色，满足校园场景下"浏览 → 下单 → 交易 → 互动"的完整闭环。

---

## 二、技术栈

- **后端**：Spring Boot 2.2.2（Java 8）、MyBatis-Plus、Apache Shiro、MySQL、WebSocket；AI 能力基于阿里云通义千问（DashScope）与百度 AI SDK
- **管理后台**：Vue 3 + TypeScript + Vite + Pinia + Vue Router + Element Plus + ECharts（+ echarts-wordcloud）+ TailwindCSS
- **移动端**：uni-app（可编译 H5 / 微信小程序 / App），TabBar 导航
- **通用能力**：Axios（请求/响应拦截）、高德地图 JS API、WangEditor 富文本、Lombok、Hutool、FastJson、xlsx 导入导出、文件/图片上传

## 三、主要职责 / 主要工作（简历正文，按条写）

1. 负责系统整体架构设计与技术选型，落地"前后端分离 + RESTful API"方案，明确 Web 管理后台、跨端移动应用与服务端三端协作关系。
2. 后端基于 Spring Boot + MyBatis-Plus 搭建分层架构（Controller / Service / Dao / Entity / VO / View），结合 Apache Shiro 与 Token 机制，实现管理员、商家、用户、游客四类角色的登录鉴权与菜单级权限控制。
3. 完成 20+ 业务模块的数据库建模与接口开发，覆盖：用户、商家、商品与分类、店铺、购物车、订单与地址、论坛、系统通知、在线留言、收藏、出入库/库房/出库、问诊咨询、预约、租赁、轮播图配置、文件上传、AI 智能问答等，并封装分页、条件查询、批量删除等通用能力。
4. 管理后台基于 Vue 3 + TypeScript + Element Plus + Pinia 实现各模块增删改查页面、路由守卫、Axios 拦截（Token 注入、401 自动跳转、错误统一提示）及 ECharts 数据可视化（含词云）。
5. 移动端基于 uni-app 实现登录/注册、商品浏览与详情、购物车、订单确认与地址管理、论坛发布与回复、在线留言、系统通知、用户充值等核心功能，并适配多端运行。
6. 集成 WebSocket 实现实时聊天与消息（Chat / Letter），打通商家与用户的即时沟通链路。
7. 引入阿里云通义千问大模型，开发 OpenAi 智能问答接口，为"问诊/咨询"等场景提供 AI 辅助能力。
8. 实现图片/文件上传、轮播图管理、Excel 数据导出等通用组件与基础设施，提升后台运营效率。

## 七、代码层面的关键事实（面试防追问，来自实际代码）

- 后端包名：`com`（主类 `SpringbootSchemaApplication`），分层：`controller / service / service.impl / dao / entity / entity.vo / entity.view / utils / annotation / config`。
- 权限：Shiro 1.3.2 + 自定义 `TokenService`，登录接口按角色走不同表（yonghu / shangjia / users），前端以 `Session` 存 `tableName / role / accessToken`。
- 前端工程名 `jmhjglxt-admin`，路由用 `createWebHashHistory`，全局请求拦截在 `utils/request.ts`（Token 注入 + 401 跳登录 + 超时/网络错误提示）。
- AI 部分：`OpenAiController` 调用 `com.utils.Main.callWithMessage()` → 阿里云通义千问 `Generation` API；另外依赖了 `com.baidu.aip` 百度 AI SDK。
- 移动端 `pages.json` 含 TabBar（首页 / 商品管理 / 店铺信息 / 论坛 / 我的），页面含购物车、订单确认、地址、充值、论坛、留言、新闻、问诊等。
- 注意：附录文档只描述了部分模块，实际代码还包含 **问诊(wd)、预约(appointment)、租赁(lease)、聊天(Chat)、信件(Letter)、库房(Kufangxinxi)、出库(Chukuxinxi)** 等未在文档中展开的功能，面试说到"模块"时可一并提及。
