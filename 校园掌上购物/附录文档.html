校园掌上购物系统 - 附录文档

附录一：系统使用说明书

1. 系统概述

校园掌上购物系统是一款专为校园场景设计的综合性购物平台，采用Vue 3 + TypeScript + Element Plus技术栈开发，提供用户、商家、管理员三种角色的完整功能支持。系统主要包含商品管理、店铺管理、订单管理、论坛互动等核心模块。

技术架构：前端框架采用Vue 3，状态管理使用Pinia，路由管理使用Vue Router，UI组件库为Element Plus，图表组件使用ECharts，构建工具为Vite。

2. 用户角色说明

系统支持四种用户角色，不同角色拥有不同的功能权限：

管理员
  • 商品管理：新增、修改、删除、查看、审核、出入库、查看评论、回复
  • 店铺管理：审核、查看、修改、删除、查看评论、回复
  • 订单管理：查看所有状态订单
  • 用户管理：新增、删除、查看
  • 商家管理：新增、修改、删除、查看
  • 系统管理：轮播图管理、系统通知
  • 出入库管理、论坛管理、在线留言管理
商家
  • 商品管理：新增、删除、修改、查看、出入库、查看评论、回复
  • 店铺管理：新增、删除、修改、查看、查看评论、回复
  • 订单管理：查看并处理订单（发货等操作）
  • 系统通知、论坛管理、在线留言
用户
  • 商品管理：查看商品、查看评论、回复评论
  • 店铺信息：查看店铺、查看评论、回复评论
  • 我的收藏管理：查看、删除收藏
  • 系统通知、论坛、在线留言
游客
  • 仅可查看系统通知

3. 功能模块介绍

3.1 商品管理模块
  • 商品列表：展示所有商品信息，支持分页、搜索、筛选
  • 商品详情：查看商品详细信息、图片、价格、库存等
  • 商品操作：新增、编辑、删除商品，审核商品状态
  • 出入库管理：记录商品入库、出库操作，更新库存
  • 商品评论：查看用户评论，进行回复操作
3.2 店铺管理模块
  • 店铺列表：展示所有店铺信息，支持搜索筛选
  • 店铺详情：查看店铺基本信息、商品列表
  • 店铺审核：管理员审核商家店铺申请
  • 店铺评论：查看店铺评论并回复
3.3 订单管理模块
  • 订单列表：按状态分类展示（未支付、已支付、已发货、已完成、已取消、已退款）
  • 订单详情：查看订单详细信息、商品清单、物流信息
  • 订单操作：商家可对已支付订单进行发货操作
3.4 用户管理模块
  • 用户列表：展示所有注册用户信息
  • 用户详情：查看用户个人信息、订单记录、收藏记录
  • 用户操作：新增、删除用户账号
3.5 系统管理模块
  • 轮播图管理：新增、修改、删除首页轮播图
  • 系统通知：发布系统公告和通知消息
3.6 互动模块
  • 论坛管理：查看论坛帖子，管理员可进行管理操作
  • 在线留言：查看用户留言，进行回复操作

4. 使用指南

4.1 登录操作

  1. 打开浏览器，访问系统登录页面
  2. 输入账号和密码
  3. 输入验证码（随机生成，点击可刷新）
  4. 选择登录角色（管理员/商家/用户）
  5. 点击"登录系统"按钮完成登录

4.2 密码安全

  • 密码长度需在6-30位之间
  • 支持字母、数字和特殊字符（_!@#$%^&.*）
  • 建议使用包含字母、数字、特殊字符的强密码
  • 登录后可在"个人信息"页面修改密码

4.3 权限说明

系统根据登录角色自动分配菜单权限，不同角色看到的功能菜单不同。管理员拥有最高权限，可管理所有系统功能；商家可管理自己的店铺和商品；用户可进行购物、收藏、评论等操作。

4.4 系统退出

用户登录后可随时退出系统，系统会清除登录状态和Session信息，确保账号安全。

2. 请求拦截器（utils/request.ts）

import axios from 'axios'
import type { AxiosInstance } from 'axios'
import { ElMessage } from 'element-plus'
import { useAuthStore } from '@/stores/auth'
import router from '@/router'

const request: AxiosInstance = axios.create({
    baseURL: import.meta.env.VITE_APP_BASE_API as string,
    timeout: 20000,
})

// 请求拦截器
request.interceptors.request.use((config) => {
    const authStore = useAuthStore()
    const accessToken = authStore.accessToken
    if (accessToken) {
        config.headers['Token'] = accessToken
    }
    return config
}, (error) => {
    return Promise.reject(error)
})

// 响应拦截器
request.interceptors.response.use(response => {
    const { data } = response
    if (data.code === 0) {
        return data
    } else if (data.code === 401) {
        ElMessage.error(data.msg)
        setTimeout(() => {
            router.push({ path: '/login' })
        }, 300)
    }
    ElMessage.error(data.msg)
    return Promise.reject(response)
}, error => {
    const { message, response } = error
    if (message.indexOf('timeout') != -1) {
        ElMessage.error('网络超时！')
    } else if (message == 'Network Error') {
        ElMessage.error('网络连接错误！')
    } else {
        if (response.data) ElMessage.error(response.statusText)
        else ElMessage.error("接口路径找不到")
    }
    return Promise.reject(error)
})

export default request

3. 认证状态管理（stores/auth.ts）

import { defineStore } from 'pinia'
import { GetToken } from '@/api/auth'
import { Session, Local } from '@/utils/storage'

export const Key = {
    accessTokenKey: 'accessToken',
    userInfoKey: 'userInfo',
}

export const useAuthStore = defineStore('auth', {
    state: () => {
        return {
            accessToken: Session.get(Key.accessTokenKey),
            users: Session.get(Key.userInfoKey)
        }
    },

    actions: {
        userLogin(loginData: any, url: string) {
            return new Promise((resolve, reject) => {
                GetToken(loginData, url).then((res: any) => {
                    this.accessToken = res.token
                    if (Session.get(Key.accessTokenKey) != null && Session.get(Key.accessTokenKey) != '') {
                        Session.remove(Key.accessTokenKey)
                    }
                    Session.set(Key.accessTokenKey, res.token)
                    resolve(res)
                }).catch((error: Error) => {
                    reject(error)
                })
            })
        }
    }
})

7. 登录页面核心逻辑（views/login/index.vue）

<script lang="ts" setup>
import { ref, reactive, toRefs, onMounted } from 'vue'
import { isUsername, isPassword } from '@/utils/validate'
import { useAuthStore } from '@/stores/auth'
import { useRouter, useRoute } from 'vue-router'
import { Session } from '@/utils/storage'
import menu from "@/utils/menu"

const authStore = useAuthStore()
const router = useRouter()
const route = useRoute()

const state = reactive({
    loading: false,
    loginData: {
        username: '',
        password: '',
        role: ''
    } as LoginData,
    tableName: ''
})

const menus = menu.list()
const { loading, loginData, tableName } = { ...toRefs(state) }

const showPassword = ref(false)
const formData = reactive({ captcha: '' })
const captchaCode = ref('')

const generateCaptcha = () => {
    const chars = 'ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnpqrstuvwxyz23456789'
    let captcha = ''
    for (let i = 0; i < 4; i++) {
        captcha += chars.charAt(Math.floor(Math.random() * chars.length))
    }
    return captcha
}

const refreshCaptcha = () => {
    captchaCode.value = generateCaptcha()
}

const togglePassword = () => {
    showPassword.value = !showPassword.value
}

onMounted(() => {
    refreshCaptcha()
})

const handleSubmit = async () => {
    state.loading = true
    try {
        if (!state.loginData.username || !state.loginData.password) {
            notify("账号密码不能为空", { type: "error" })
            return
        }
        if (captchaCode.value.toUpperCase() !== formData.captcha.toUpperCase()) {
            notify("验证码错误", { type: "error" })
            refreshCaptcha()
            return
        }
        for (let i = 0; i < menus.length; i++) {
            if (menus[i].roleName == state.loginData.role) {
                state.tableName = menus[i].tableName
            }
        }
        const res = await authStore.userLogin(state.loginData, `${state.tableName}/login`)
        Session.set("tableName", state.tableName)
        Session.set("role", state.loginData.role)
        Session.set("adminName", state.loginData.username)
        router.replace({ path: route.query?.redirect || '/' })
    } finally {
        state.loading = false
    }
}
</script>

8. 验证工具（utils/validate.ts - 核心验证函数）

// 校验用户名：6-30位数字、字母和下划线
export function isUsername(str: string) {
    const valid_map = /^[a-zA-Z0-9_:]{6,30}$/
    return valid_map.test(str)
}

// 校验密码：6-30位字母、数字和特殊字符
export function isPassword(str: string) {
    const valid_map = /^[0-9a-zA-Z_!@#$%^&\.*]{6,30}$/
    return valid_map.test(str)
}

// 校验手机号
export function isMobile(str: string) {
    const valid_map = 11 && /^1(3|4|5|7|8|9)\d{9}$/
    return valid_map.test(str)
}

// 校验邮箱
export function isEmail(str: string) {
    const valid_map = /^[A-Za-z0-9\u4e00-\u9fa5]+@[a-zA-Z0-9_-]+(\.[a-zA-Z0-9_-]+)+$/
    return valid_map.test(str)
}

// 验证码验证：4~6位数字、字母
export function isCheckCode(str: string) {
    const valid_map = /^[0-9a-zA-Z]{4,6}$/
    return valid_map.test(str)
}

// 密码强度判断
export function isPasswordStrength(str: string) {
    let v = '弱'
    if (/^(?:\d+|[a-zA-Z]+|[!@#$%^&\.*]+){6,30}$/.test(str)) v = '弱'
    else if (/^(?![a-zA-z]+$)(?!\d+$)(?![!@#$%^&\.*]+$)[a-zA-Z\d!@#$%^&\.*]{6,30}$/.test(str)) v = '中'
    else if (/^(?![a-zA-z]+$)(?!\d+$)(?![!@#$%^&\.*]+$)(?![a-zA-z\d]+$)(?![a-zA-z!@#$%^&\.*]+$)(?![\d!@#$%^&\.*]+$)[a-zA-Z\d!@#$%^&\.*]{6,30}$/.test(str)) v = '强'
    return v
}
